# Security Policy

## Reporting a vulnerability in deps.dev

To report a security vulnerability in deps.dev (the https://deps.dev website,
the deps.dev API, or the code in this repository), please use
[https://g.co/vulnz](https://g.co/vulnz) (Google's Vulnerability Reward
Program at https://bughunters.google.com). Please do not file public GitHub
issues for security problems.

We use g.co/vulnz for intake and triage. Vulnerabilities in the deps.dev
website or API are handled privately by Google and fixed in our services.
For valid issues in the code in this repository, we will do coordination and
disclosure here on GitHub (including using a GitHub Security Advisory when
necessary). The Google Security Team will process your report within a day,
and respond within a week (although it will depend on the severity of your
report).
